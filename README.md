# pixel-palette
Pixel Palette is a web-based visual design and code-generation platform that lets users create interactive web designs using text, shapes, images, buttons, and containers. It provides customization, layers, responsive previews, and undo/redo, while automatically generating HTML/CSS code that users can preview, copy, and export.
